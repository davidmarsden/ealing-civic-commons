How to read this

Evidence, not editorial.

Each result keeps the indicator name, geography, date, ArcGIS field and underlying service visible. The probe discovers Southall-related features from Ealing’s own geography layers and then follows the catalogue pointers to the value services.

If a geography or indicator cannot be matched safely, the page says so rather than silently guessing.
