Ealing implementation documents

Ealing is the first working Civic Commons. Its source census, architecture, partnership thinking, development history and roadmap remain public as a reference implementation — not as rules every locality must copy.

Network guidance

The shared model now lives at civiccommons.co.uk. Start with the Charter, then use the practical field guide if you want to build a Commons somewhere else.
