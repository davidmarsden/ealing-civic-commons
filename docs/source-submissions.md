# Source submissions

The Phase 1 prototype accepts source suggestions through a Netlify Form named `submit-source`.

Submissions are proposals for human review, not automatic additions to the feed set.

Review should consider:

- local relevance to one or more of Ealing's seven towns;
- source identity and provenance;
- whether the site has a stable RSS/Atom/JSON feed or other agreed integration route;
- source classification (official record, journalism/publishing, organisation/campaign, data/research);
- copyright and attribution requirements;
- whether inclusion would materially improve geographic or civic coverage.

Netlify's form dashboard is the initial review inbox. A later phase can replace this with a structured source-registry workflow if submission volume warrants it.
